# rice

Dotfiles do meu setup Hyprland (CachyOS): Hyprland (Lua), Waybar, Rofi, SwayNC,
wlogout, btop, Neovim, fish, GTK e o tema de login SDDM `hypr-login`.

## Layout
- `config/`  → copiar para `~/.config/`
- `sddm/hypr-login/` → `/usr/share/sddm/themes/hypr-login/` (root)
- `sddm/30-sddm-general.conf` → `/etc/sddm.conf.d/` (root)

Segredos (ex.: `fish/wol.env`) ficam fora do repo.
